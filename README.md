# Piyo · landing

Static landing page that invites people to contribute to the Piyo repositories
([piyo-app](https://github.com/pedro-cv/piyo-app), [piyo-backend](https://github.com/pedro-cv/piyo-backend)).
Astro, GSAP + Lenis for motion, three.js for the hero seam, a 2D-canvas runner game. Spanish, with camba
vocabulary that anyone can extend.

```sh
npm install
npm run images     # maintainers only: regenerates src/assets from the original photos (not in this repo)
npm run dev        # http://localhost:4321
npm run build      # dist/
npm run preview
```

Deploys must set `PUBLIC_SITE` (absolute origin; it builds the `og:image` URL, omitted otherwise) and, on a sub-path such as GitHub Pages, `PUBLIC_BASE`:
`PUBLIC_SITE=https://<user>.github.io PUBLIC_BASE=/piyo-landing/ npm run build`.

## Edit the content

| What | Where |
|---|---|
| Slang words (hero seam, Palabras section) | `src/data/words.json` — word, meaning in Spanish, English translation |
| Game obstacles | `src/data/obstacles.json` + a sprite in `src/scripts/sprites.ts` |
| Repo links (app, backend, this page), contact email, facts, image captions and credits | `src/data/site.json` |
| Colours, type scale | `src/styles/tokens.css` |
| Favicons and web-app icons | generated by `npm run images` from `design/icons/icon_no_background.png`, same composition as the Android launcher icon |

The brand colour is one green, `#2a6a47` (`--brand` in `tokens.css`, `@color/brand_green` in the app): launcher icon
background, app primary, landing accent, favicon and `theme-color`. Change it in both places or nowhere.

The processed images are committed, so `npm run dev` / `npm run build` work without the originals.

Sprites are tiny strings (`#` ink, `o` accent, `.` empty), so adding an animal is a pull request with no tooling.

## Accessibility and motion

Everything animates with GSAP/ScrollTrigger and degrades to visible-and-still under `prefers-reduced-motion`
(Lenis off, hero seam off). The game is keyboard (Space/↑ jump, ↓ duck) and touch (tap jump, swipe down or
lower-third press to duck) friendly and pauses when the tab is hidden.

## Contributing

Fork, branch, `npm run check && npm run build` green, open a pull request. A new word is a one-object edit in
`src/data/words.json` (GitHub's web editor is enough). Not a developer? Write to
[pedro.cv.dev@gmail.com](mailto:pedro.cv.dev@gmail.com) with the idea, bug or word.
